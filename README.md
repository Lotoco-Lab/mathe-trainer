# Mathe-Trainer

Rechnen üben für die 3. Klasse (Baden-Württemberg): Plus, Minus, Mal, Geteilt und Gemischt in drei Stufen,
je zehn Aufgaben, große Zahlentasten, freundliche Rechenhilfen, Wiederholung kniffliger Aufgaben,
Fortschritt nur auf dem Gerät. PWA, läuft komplett offline – ohne Konto, Werbung oder Kosten.

- Schnellstart: `python3 tools/test.py` (Build + Tests), `python3 tools/serve-https.py` (iPhone-Test)

- Testbericht: [docs/TESTBERICHT.md](docs/TESTBERICHT.md)
